# Poppins fonts

These unmodified Poppins font files are bundled so stateful cover-letter PDFs render
deterministically inside the isolated Typst compiler container.

Source: [Google Fonts — Poppins](https://github.com/google/fonts/tree/main/ofl/poppins)
